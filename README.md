# GCAF_DRIFTWAVES
Here you can find the GCAF code (a Guiding Center code for a axisimetrical toroidal geometry) in presence of electrostatic drift waves.

Final containts the c++ codes needed for running GCAF on a cluster, and also provides some shell scripts to run bigger batchs of code.

Miscellaneous Codes have all the code for plotting the results from GCAF.
